# Videos

Finished signature videos, 4K vertical (2160x3840), HEVC (H.265) so each file stays under
GitHub's 100 MB limit. On a phone: tap a file, download it, then Share -> Save Video.

- `drone_mountain_final.mp4`: the latest version (mountain graded separately while the camera washes it out; the forest brightened like exposure, so the aspens don't fade and each evergreen is the same green top to bottom).
  Older versions of the same file are in this branch's history.
- `drone_mountain_v3_trees_fixed.mp4`: an earlier version (the browns shift around 12 s).

The scripts that make them are on the `signature-overlay-cloud` branch (`signature_overlay/`).
